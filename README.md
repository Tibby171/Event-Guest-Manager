# Event-Guest-Manager
**Event Guest Manager – Dynamic Guest Registration and Interaction System**

**Event Guest Manager** builds upon the original guest management system to provide a user-friendly command-line interface for efficiently handling guest registrations, updates, searches, and more. It integrates interactive functionality, ensuring a seamless experience for both event organizers and participants.

_**Key Features:**_

Streamlined Guest Addition: Add new attendees effortlessly to the main guest list or waiting list based on capacity, with personalized messages for each.

Flexible Search Options: Search for guests by name, email, phone number, or even partial keyword matching to find attendees across both the guest list and waiting list.

Guest Updates: Modify attendee details, including names, email, or phone number, to accommodate changes in participant information.

Comprehensive Removal Mechanism: Remove attendees by name, email, or phone number, with automatic promotion of waiting list members when spots become available.

Dynamic List Visualization: View the full guest list, waiting list, available spots, and total registered participants for quick and efficient event organization.

Command Line Interaction: A set of intuitive commands allows users to interact with the system in real-time, streamlining event management tasks.

_**Command Options:**_

Add New Guests: Utilize add to register a guest for the event or add them to the waiting list.

Search for Attendees: Use check or search commands to locate guests by various criteria or keywords.

Update Guest Details: Modify attendee information directly using the update command.

Manage Lists: Display guest or waiting lists with guests and waitlist. Remove attendees with the remove command.

Event Insights: Find available spots (available), current guest count (guests_no), waiting list size (waitlist_no), or total participant count (subscribe_no).

Help Command: Use help to display all available commands for ease of operation.

Quit Application: Exit the program with the quit command.

_**Benefits:**_

Provides real-time interaction and flexibility, enabling efficient management of guests and event resources.

Offers a practical solution for events of any size, reducing the complexity of participant tracking and updates.

Enhances user experience with detailed insights, customizable lists, and automated waiting list handling.
